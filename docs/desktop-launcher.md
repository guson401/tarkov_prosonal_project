# 데스크톱 앱 실행과 런처 빌드

이 프로젝트의 데스크톱 앱은 **Tauri 2 + Vite**로 구성되어 있습니다. 개발 중에는 Vite 개발 서버를 연결한 앱으로 실행하고, 배포할 때는 Tauri가 프론트엔드와 Rust 앱을 묶어 설치 파일을 만듭니다.

## 준비 사항

- Node.js와 npm
- Rust 툴체인
- Windows에서 빌드할 경우 Tauri가 요구하는 C++ 빌드 도구와 WebView2

## 개발 모드로 실행하기

프로젝트 루트에서 실행합니다.

```powershell
npm.cmd run tauri:dev --workspace @tarkov/desktop
```

개발용 데스크톱 창이 열립니다. 프론트엔드 코드를 수정하고 저장하면 Vite가 변경된 화면을 자동으로 다시 불러옵니다. 일반적으로 앱을 매번 다시 빌드할 필요는 없습니다. Rust 쪽 변경은 자동 화면 갱신 대상이 아니므로 앱을 다시 시작하거나 재빌드해야 할 수 있습니다.

## 런처(설치 앱) 만들기

프로젝트 루트에서 실행합니다.

```powershell
npm.cmd run tauri:build --workspace @tarkov/desktop
```

Tauri가 프론트엔드를 빌드한 다음 Windows용 배포 산출물을 만듭니다. 산출물은 보통 다음 경로 아래에 생성됩니다.

```text
apps/desktop/src-tauri/target/release/bundle/
```

실제 파일 형식과 폴더 이름은 `tauri.conf.json`의 번들 타깃 설정과 빌드 환경에 따라 달라질 수 있습니다. 이 프로젝트는 번들 타깃을 `all`로 설정했습니다.

## 수정 사항이 반영되는 시점

| 실행 방식 | 코드 수정 후 반영 |
| --- | --- |
| 개발 모드 (`tauri:dev`) | 프론트엔드 변경은 저장 후 개발 창에 자동 반영됩니다. |
| 빌드한 설치 앱 | 이미 만들어진 앱에는 반영되지 않습니다. 다시 빌드하고 새 산출물을 설치해야 합니다. |

설치 앱 업데이트를 사용자에게 자동 배포하려면 별도의 업데이트 배포 설정이 필요합니다. 현재 설정만으로는 코드 수정이 기존 설치 앱에 자동으로 전달되지 않습니다.

## 앱 이름과 창 설정

제품명, 앱 식별자, 창 크기와 번들 설정은 다음 파일에서 관리합니다.

```text
apps/desktop/src-tauri/tauri.conf.json
```

제품명이나 아이콘 등을 변경한 뒤에는 새 배포 앱을 다시 빌드해야 합니다.
